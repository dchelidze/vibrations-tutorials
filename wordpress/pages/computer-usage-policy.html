Software licensing and computer usage policy

Guidelines for properly using NLD computers, software licenses, research data, AI tools, and URI networks. Applies to all graduate and undergraduate students, collaborators, interns, and personnel with access to NLD computing facilities.

Research data, code and AI tools

  • Keep raw data, processed data and analysis code for lab projects in the NLD shared Drive, not only on a personal laptop or account. Record how each data set was measured or generated.
  • Keep code under version control. Code the lab releases goes to the nld-uri GitHub organization after the director approves the release.
  • Use AI tools through the lab’s URI-NLD Claude organization or other tools the director approves.
  • Do not enter confidential material into AI tools that are not approved. This includes unpublished data, manuscripts you are reviewing, sponsor-restricted or export-controlled information, and personal data.
  • You are responsible for every result, line of code and sentence you submit, whoever or whatever drafted it. Check AI output against the data and the literature, and never cite a reference you have not read.
  • Disclose AI use as each journal, sponsor and URI requires.

Acceptable Use, Monitoring & Compliance

Computer, network, and workstation standards

Proper computer, email, and internet usage

All NLD personnel are expected to use computer devices, the internet, and URI’s computer networks to work on their research-project- and coursework-related tasks. They use the email system and social media only for NLD-related purposes. All NLD computer users are expected to:

  • Use secure passwords and keep their user ID information private.
  • Not give their computer login information to others or grant them unauthorized access to the NLD’s computer system.

Abuse of policy and inappropriate usage

Laboratory personnel should not use NLD computers to:

  • Install or use unlicensed or pirated software.
  • Download or upload illegal files or spread illegally copyrighted materials.
  • Send confidential information to unauthorized user accounts.
  • Invade others’ privacy, corporate accounts, and email communication.
  • Visit unsafe websites that can crash the system or spread a virus in URI’s network.
  • Engage in hacking activities, steal personal or financial information, mine cryptocurrencies, or buy/sell illegal goods.
  • Turn off firewalls or antivirus programs without administrator or manager permission.

Monitoring, security & workstations

Monitoring. URI has the right to monitor regularly all electronic communication channels on URI computing devices. NLD personnel should not assume communication on these devices is exclusively private and should not transmit private messages or personal data.

Security. Do not share authorized access information, attempt to obtain colleagues’ passwords, hack into other networks, or jeopardize NLD system security.

Workstations. Each workstation is used by one researcher or student at a time (with director-approved admin access if needed). Report any installed software package changes to the lab director.

Consequences for non-compliance

NLD personnel who violate this computer usage policy will face disciplinary action. A warning will follow minor violations; depending on severity, research associates or students can face termination of employment, expulsion from URI, and legal action. Examples of severe violations include:

  • Using computer devices for illegal activity, including installing or using unlicensed or pirated software.
  • Activities that spread malware such as viruses, worms, and Trojan horses.
  • Spreading discriminatory, offensive, or harassing messages (zero-tolerance policy).
