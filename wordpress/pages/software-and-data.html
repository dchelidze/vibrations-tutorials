MATLAB & Python · Monograph Code

Experimental Nonlinear Dynamics: book code

MATLAB and Python code for the book Experimental Nonlinear Dynamics by D. Chelidze and J. P. Cusumano. Covers delay embedding (AMI, FNN), correlation dimension, Lyapunov exponents, recurrence quantification, spectral estimation, surrogate data, POD and SOD noise reduction, and phase space warping, plus all figure scripts, two example datasets, and the book draft PDF.

MATLAB & Python · Signal Processing

Kinematics toolbox

Model-free differentiation and integration of measured motion. Estimates velocity and acceleration from noisy displacement, or velocity and displacement from a drifting accelerometer, and fuses both channels using regularity priors (Whittaker–Henderson, Tikhonov, TV, Kalman/RTS).

MATLAB & Python · Modal Identification

NCVD toolbox

Nonlinear Characteristic Value Decomposition: modal identification from state records with exact identities, pole correction for numerical derivatives, noise-robust operators, measured forcing, ensembles of records, and amplitude-dependent identification of nonlinear structures (backbone curves).
